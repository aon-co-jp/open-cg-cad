# open-cg-cad

*日本語*: [README.md](README.md) · *English*: [README-English.md](README-English.md)

CAD-система для функций «ИИ-строительная компания и ИИ-здание». Проверяет
градостроительные нормы (право на солнечный свет, коэффициент застройки,
коэффициент плотности застройки и т. д.), автоматически создаёт 3D-объёмы
зданий в виде CAD-данных, применяет простую окраску и может предлагать
несколько методов строительства.

**Добавлено 2026-08-27**: Функция переработки старых чертежей
полупроводников (CPU/NPU/GPU) и транспортных средств (автомобилей/
мотоциклов/синкансэнов/поездов на магнитной подушке/самолётов, включая
бензиновые/дизельные/электрические/гибридные двигатели PHEV) —
текстовое описание старого чертежа сопоставляется с новой инструкцией или
повторно загруженным документом спецификации, и ИИ создаёт предложение по
переработке — а также агенты чтения-записи для GitHub и VPS/арендованного
сервера. Полный объём и честное раскрытие того, что реализовано (а что
нет), см. в [CLAUDE.md](CLAUDE.md) (на японском языке) — в частности:
никакие физические, электрические или аэродинамические симуляции не
выполняются, реальные геометрические данные CAD не изменяются; это
исключительно текстовая консультация ИИ.

`https://easy-web.tokyo/open-cg-cad/` работает в реальном времени; точка
входа для демонстрации и загрузки (для локального использования на
собственном диске) находится по адресу
`https://easy-web.tokyo/open-cg-cad/demo`.

**Важный отказ от ответственности**: Эта система — лишь инструмент для
создания черновиков/образцов, предшествующий окончательной проверке
квалифицированными специалистами (архитекторами и т. д.) — она не создаёт
юридически утверждённые или готовые к подаче на разрешение планы.
