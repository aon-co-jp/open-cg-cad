# open-cg-cad

*日本語*: [README.md](README.md) · *English*: [README-English.md](README-English.md)

CAD-система для функцій «ШІ-будівельна компанія та ШІ-будівля». Перевіряє
містобудівні норми (право на сонячне світло, коефіцієнт забудови,
коефіцієнт щільності забудови тощо), автоматично створює 3D-об'єми
будівель як CAD-дані, застосовує просте забарвлення та може пропонувати
декілька методів будівництва.

**Додано 2026-08-27**: Функція переробки старих креслень напівпровідників
(CPU/NPU/GPU) та транспортних засобів (автомобілів/мотоциклів/сінкансенів/
поїздів на магнітній подушці/літаків, включно з бензиновими/дизельними/
електричними/гібридними двигунами PHEV) — текстовий опис старого
креслення порівнюється з новою інструкцією або повторно завантаженим
документом специфікації, і ШІ створює пропозицію щодо переробки — а також
агенти читання-запису для GitHub та VPS/орендованого сервера. Повний обсяг
і чесне розкриття того, що реалізовано (а що ні), див. у
[CLAUDE.md](CLAUDE.md) (японською мовою) — зокрема: жодні фізичні,
електричні чи аеродинамічні симуляції не виконуються, реальні геометричні
дані CAD не змінюються; це виключно текстова консультація ШІ.

`https://easy-web.tokyo/open-cg-cad/` працює в реальному часі; точка входу
для демонстрації та завантаження (для локального використання на власному
диску) знаходиться за адресою `https://easy-web.tokyo/open-cg-cad/demo`.

**Важливе застереження**: Ця система — лише інструмент для створення
чернеток/зразків, що передує остаточній перевірці кваліфікованими
фахівцями (архітекторами тощо) — вона не створює юридично затверджені або
готові до подання на дозвіл плани.
