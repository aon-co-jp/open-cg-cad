🏗 open-cg-cad: AI工務店&AI建設 / AI construction & contractor assist (Phase 0)

重要な免責事項: これは意匠検討の叩き台生成ツールであり、建築確認申請に使える正式な設計図面ではありません。日照権・耐震性・避難計画等の実シミュレーションは行っておらず、法規制パラメータは利用者が入力した値をそのまま使うだけです(自動取得はしません)。実際のプロジェクトには一級建築士・宅地建物取引士等の有資格者によるレビューが必須です。

Honest disclosure: This is a draft massing tool only, not a permit-ready design. No real sunlight-rights, seismic, or evacuation simulation is performed, and zoning parameters are used exactly as entered (no automatic lookup). A licensed architect/professional must review any real project.
これはデモです / This is a demo. ローカルドライブへダウンロードしてご自身の環境で運用する場合は、 GitHubのソースコード(aon-co-jp/open-cg-cad) から取得し(`git clone`+`cargo build --release -p open-cg-cad-server`)、 ご自身のPC/サーバー上で起動してください。正直な開示: 現時点ではワンクリックのインストーラー(open-english同様の `.exe`/`install.sh`)はまだ用意していません——ソースからのビルドが 必要です。

To download and run this on your own drive/server, get the source from GitHub (aon-co-jp/open-cg-cad) and build it yourself (`git clone` + `cargo build --release -p open-cg-cad-server`). Honest disclosure: there is no one-click installer yet (unlike open-english) — building from source is currently required.
